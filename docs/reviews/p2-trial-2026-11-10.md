# P2 시험 운용 기록 (2026-11-10)

- 대상: 시험용 원고 저장소(비공개)에서 이미 원고가 있는 장 하나(이하 '시험 장')
  - 다른 세션이 같은 날 `extract`를 돌려 둔 장은 피했습니다.
- 설치: 마켓플레이스 설치본 book-writer 0.1.2, shared 0.1.0, Claude Code 2.1.322
- 실행 방식: 메인 대화가 원고 저장소에서 `claude -p` 세션을 띄워 book-writer 에이전트를 불렀습니다. 이유는 발견 1에 있습니다.
- 결과: 원고 저장소 커밋(push 완료)

## 흐름과 결과

| 단계 | 맡은 쪽 | 결과 |
|---|---|---|
| `extract` | planner | `plans/vol<N>/ch<NN>/` 세 문서를 만듦. 안 A(현행)와 대안 B·C, 물어볼 것 5개 |
| 관문 | 사람 | 안 A 승인. 메인 세션이 세 문서에 `상태: 승인`과 결정 사항을 적고, manifest 상태를 `검토`로 바꿈 |
| ⑤ r1 | editor | 수정 필요(blocker 0, major 2, minor 6) |
| ⑤ r1 외부 | Antigravity, `shared:review-packet`, 관점 spec | major 2(editor와 같음), minor 1(기각). 판정 표: `reviews/antigravity-<범위>-<날짜>-r1.md` |
| 실측 | capturer `probe` | 본문 요청문 두 개를 각각 2회·1회 실행. 원고와 다른 점 3개 |
| 관문 | 사람 | major 하나(본문 근거)를 "지금 실측 후 반영"으로 결정 |
| 반영 | writer `revise` | major 2와 minor 5를 반영. minor 1은 근거를 남기고 미반영 |
| 검증 | 메인 세션 | 표기 검사 0, 권 빌드 성공(장 쪽수 유지), 예제 꾸러미 테스트 21개 통과 |
| ⑤ r2 | editor | **승인**(blocker 0, major 0, minor 3) |

## §0 실측 재확인 (마켓플레이스 설치본)
- `skills:` 미리 로드는 작동합니다. 다섯 에이전트 모두 필수 스킬 본문이 컨텍스트에 있었습니다.
- 접두사를 붙인 호출(`book-writer:book-workflow`, `book-writer:screen-capture`)은 정상입니다.
- 쓰기 가드는 역할별 허용 경로대로 판정했습니다. 원고 저장소 안에서 막힌 정상 쓰기는 없었습니다.

## 발견 (고칠 것)

| # | 발견 | 영향 | 고칠 곳(제안) |
|---|---|---|---|
| 1 | 쓰기 가드는 **세션 cwd**에서 위로 `manifest.md`를 찾아 루트를 정합니다. 다른 저장소에서 연 세션이 book-writer 에이전트를 부르면 원고 쓰기가 모두 막힙니다 | 안전한 쪽으로 막히지만, 쓰는 사람이 이유를 모름 | book-writer README와 `book-workflow`에 "원고 저장소에서 연 세션에서 씁니다" 명시. 거부 메시지에 찾은 루트와 이유를 표시 |
| 2 | 0단계의 「불러온 스킬」 문구가 모호합니다. 스킬이 `skills:`로 미리 로드돼 있으면 "없음"으로 보고됩니다(planner) | 0단계 확인의 목적(스킬 누락 탐지)을 보고서로 판단할 수 없음 | 다섯 에이전트의 문구를 "컨텍스트에서 확인한 스킬(미리 로드 + `Skill` 호출)"로 바꿈. work-standards·docu-writer 에이전트의 같은 문구도 점검 |
| 3 | editor에 Bash가 없어 ⑤의 표기 검사를 못 돌립니다(P1에서 의도적으로 뺌) | 검사 결과 없이 검토 | `book-workflow` ⑤에 "메인 세션이 표기 검사를 돌려 사실 자료로 넘김"을 적음 |
| 4 | capturer 계약은 "실습 파일 만들기 같은 임시 변경"을 허용하지만, 쓰기 가드가 저장소 밖을 막고 Bash 파일 생성도 금지합니다 | capturer 혼자서는 실습 폴더를 준비할 수 없음. 이번에는 메인 세션이 준비함 | 계약을 "실습 폴더는 메인 세션이 준비"로 고치거나, `paths.json`에 실습 폴더 허용(P1 보고서의 미결 질문) |
| 5 | capturer의 실측 기록 경로 기본값은 `research/measure-*.md`인데, 이 원고 저장소는 `reviews/measure-*.md`를 씁니다 | 기록이 두 곳으로 갈림 | 원고 저장소 `.book-writer/paths.json`으로 맞추거나 `book-principles`에 기록 위치를 한 곳으로 정함 |
| 6 | 원고 저장소 밖 실습을 실측하려면 세션을 `--add-dir <실습 폴더>`로 띄워야 합니다. 1차 실행은 `find`·`cd`가 막혀 실측 0건 | capturer는 우회하지 않고 멈춤(안전 규칙은 정상) | `screen-capture`·README에 실행 조건으로 적음 |
| 7 | capturer가 실측 원문(응답 전문)을 남길 허용 경로가 없습니다 | 실측 기록에 요약과 인용만 남음 | 허용 경로에 `research/raw/**` 같은 원문 자리를 둠 |
| 8 | writer의 "변경 범위 검증"에 필요한 명령(예제 테스트 `pytest`, 쪽수 확인)이 세션 허용 목록에 없고, 이 환경에는 `pdftotext`가 없습니다 | writer가 검증을 끝내지 못하고 메인 세션이 대신 돌림 | 원고 저장소 `.claude/settings.json`에 검증 명령 허용을 두거나, `book-workflow`에 "검증 실패·미실행은 메인 세션이 돌린다"를 적음. 쪽수는 pypdf로 확인 가능 |
| 9 | editor r2는 계획 문서와 DECISIONS·manifest를 직접 읽지 않고 r1 인용으로 대신했습니다 | 2회차 판정의 기준 대조가 얕아짐 | editor 「정찰」에 "회차와 관계없이 계획 문서 세 개를 직접 읽음"을 적음 |

## 남은 원고 일(⑥ 완료 단계, P2 범위 밖)
- editor r2 minor 3건이 남아 있습니다. 뒤 장과 용어 맞추기, 본문과 예제 꾸러미의 파일 이름 맞추기, 지적 하나의 실측 여부입니다.
- 폴더 신뢰 창과 허락 창 문구는 대화형으로 실측해야 합니다(capturer `shoot`).
- 실습 폴더 두 개는 실측 재현용으로 남겨 두었습니다.
