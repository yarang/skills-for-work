# 신규 문서 작성 (준비 중)

견본 없이 새 문서를 쓰는 절차입니다. 아직 쓰지 않았습니다. 지금은 견본·양식 파일이 있는 작업만 `template-workflow`로 진행합니다.

계획(설계서 §9):
- ② `analyst` 대신 `planner`가 문서 종류 스킬로 목차를 설계하고, `design-theme`으로 디자인 토큰을 골라 **견본 모드와 같은 형식의 프로파일**을 만듭니다.
- ⑤부터는 1단계와 같은 `writer`, `doc-verify`, `reviewer`를 씁니다.
- 출력은 Markdown으로 쓴 뒤 pandoc·soffice 또는 kordoc `generate_document`로 변환합니다.
