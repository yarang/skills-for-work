# 백엔드 원칙

**기본 대상은 오래 실행되는 서비스**입니다. CLI·TUI·데스크톱 네이티브는 맨 아래 「예외」 절을 먼저 확인합니다.

## 프로세스 수명

- **정상 종료**: SIGTERM/SIGINT를 받으면 새 요청을 받지 않고, 진행 중인 작업을 마치고, 연결을 닫고 종료합니다. 종료 대기에는 상한(예: 30초)을 둡니다.
- 시작 시 필수 설정과 외부 자원 연결을 확인하고, 실패하면 **바로** 0이 아닌 코드로 종료합니다. 반쯤 뜬 상태로 요청을 받지 않습니다.
- 헬스체크는 "살아 있음"(liveness)과 "요청 받을 준비됨"(readiness)을 구분합니다.

## 출력 스트림과 로그

- **stdout은 프로그램의 출력**(프로토콜, 데이터)용이고, **로그는 stderr**로 보냅니다. stdio로 통신하는 프로세스(MCP stdio 서버 등)에서는 이 규칙을 어기면 프로토콜이 깨집니다.
- 로그는 구조화(키-값 또는 JSON)합니다. 요청 ID 같은 상관 ID를 붙입니다.
- 비밀값, 토큰, 개인정보를 로그에 남기지 않습니다. 요청·응답 전체를 덤프하지 않습니다.
- 로그 레벨: 운영자가 조치해야 하면 ERROR, 예상된 실패는 WARN 또는 INFO입니다. 사용자 입력 오류는 ERROR가 아닙니다.

## 설정

- 설정은 **환경변수**로 받습니다. 시작 시 한 번 읽어 타입 있는 설정 객체로 검증하고, 그 객체를 주입합니다. 코드 곳곳에서 환경변수를 직접 읽지 않습니다.
- 비밀값은 환경변수나 비밀값 저장소에서 받습니다. `.env`는 로컬 개발용이며 커밋하지 않습니다. 대신 `.env.example`을 커밋합니다.

## 외부 호출

- 모든 네트워크 호출에 **타임아웃**을 둡니다. 기본값 무제한인 클라이언트를 그대로 쓰지 않습니다.
- 재시도는 **멱등한 작업에만**, 지수 백오프와 지터를 두고, 횟수 상한을 둡니다. 4xx(429 제외)는 재시도하지 않습니다.
- 쓰기 작업을 재시도할 수 있게 하려면 멱등성 키를 둡니다.
- 연결 풀은 프로세스당 하나를 만들어 주입합니다. 요청마다 클라이언트를 만들지 않습니다.

## 동시성

- 비동기 런타임에서 블로킹 호출(동기 I/O, CPU 집약 작업, `sleep`)을 하지 않습니다. 별도 스레드 풀로 보냅니다.
- 백그라운드 작업은 종료 시 정리됩니다. 고아 태스크를 만들지 않습니다.
- 공유 상태는 최소화하고, 필요하면 락 범위를 짧게 둡니다. 락을 쥔 채 await하지 않습니다.

## 데이터

- 스키마 변경은 마이그레이션 파일로만 합니다. 마이그레이션은 되돌릴 수 있거나, 되돌릴 수 없다고 명시합니다.
- 목록 조회에는 페이지네이션과 상한을 둡니다. 루프 안에서 쿼리를 날리지 않습니다(N+1).
- 여러 쓰기가 함께 성공해야 하면 트랜잭션으로 묶습니다.

## Node 런타임 (backend-node)

- `process.on('unhandledRejection')`을 처리하고 종료합니다. 조용히 넘기지 않습니다.
- 이벤트 루프를 막는 동기 API(`fs.readFileSync` 등)는 시작 시점에만 씁니다.
- 프론트엔드 코드와 공유하는 모듈에 Node 전용 API(`fs`, `process`)를 넣지 않습니다.

## 예외: CLI·TUI·데스크톱 네이티브

clap 기반 CLI, ratatui TUI, Tauri의 Rust 측처럼 **서비스가 아닌 프로세스**에는 다음이 우선합니다.

| 항목 | 서비스 | CLI | TUI | 데스크톱 네이티브 |
|---|---|---|---|---|
| stdout | 프로토콜/데이터 | **결과 출력** (파이프 가능하게) | 화면 렌더링 전용 | 쓰지 않음 |
| 로그 | stderr, 구조화 | stderr, 사람이 읽는 형식, `-v`로 단계 조절 | **파일로** (화면을 깨뜨림) | 파일 또는 OS 로그 |
| 설정 | 환경변수 | **플래그 > 환경변수 > 설정 파일** 순 | CLI와 같음 | 앱 설정 디렉터리 |
| 종료 | 시그널 → 정상 종료 | 종료 코드로 성공/실패 구분 (0/1/2) | 터미널 상태를 반드시 복구 | 창 닫힘 이벤트 처리 |
| 재시도·헬스체크 | 필요 | 대개 불필요 | 불필요 | 불필요 |
