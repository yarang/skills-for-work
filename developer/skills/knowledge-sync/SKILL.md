# 지식 저장소 동기화

저장소 문서만으로는 저장소 밖의 사람이 필요한 지식을 찾지 못합니다. 이 스킬은 지식 저장소에 올릴 **초안**을 만드는 기준입니다. 올리기 자체는 메인 대화가 사용자 승인을 받은 뒤 하므로, 여기서는 파일로 쓰는 것까지입니다.

## 무엇을 지식 저장소에 두는가

| 두는 것 | 예 |
|---|---|
| 저장소 밖 사람도 찾아야 하는 운영 지식 | 서비스 구동 절차, 장애 대응, 접근 권한 얻는 법 |
| 결정의 요약 | ADR의 한 줄 요약과 링크 |
| 여러 저장소에 걸친 내용 | 공통 인프라, 계정·비밀 관리 |

계정·비밀 관리를 다룰 때도 실제 비밀값·토큰·키·비밀번호는 초안에 넣지 않고, 관리 도구·발급 절차·보관 위치만 적습니다.

**저장소 문서와 겹치면 저장소가 원본입니다.** 지식 저장소에는 요약과 저장소 문서 링크만 둡니다. 내용을 통째로 복제하면 어느 쪽이 오래되었는지 알 수 없어져, 둘 다 못 믿게 됩니다.

## wiki와 Notion 구분

| 저장소 | 두는 것 |
|---|---|
| wiki | 기술 참조 — 설치, 구조, 결정 |
| Notion | 업무 기록 — 일정, 담당, 회의 |

기술 내용을 Notion에, 일정을 wiki에 두지 않습니다. 이미 반대로 쓰이는 자리가 있으면 그 관례를 따르고 「물어볼 것」에 적습니다.

## 초안 쓰기

초안은 `.work-standards/kb-outbox/<YYYY-MM-DD>-<제목>.md` 에 씁니다. 파일 하나가 올릴 문서 하나입니다. 머리에 다음을 적습니다:

```
대상 저장소: wiki | Notion
대상 위치: <문서를 둘 경로·페이지>
구분: 새 문서 | 갱신 — <갱신할 기존 문서 위치>
원본: <커밋 해시(또는 범위)>, <파일 경로>
```

**중복 확인**: 초안을 쓰기 전에 같은 주제가 이미 있는지 검색합니다(읽기 도구가 있을 때). 같은 주제가 있으면 `구분: 갱신` 으로 두고 그 문서 위치를 적습니다. 검색할 도구가 없으면 「확인 못 함」에 적고 `구분: 새 문서(중복 확인 못 함)` 로 둡니다.

**출처**: 초안마다 원본 커밋과 파일 경로를 적습니다. 나중에 초안 내용이 의심될 때 어디서 왔는지가 유일한 판단 근거이기 때문입니다.

## 올리지 않습니다

초안을 지식 저장소에 올리는 것은 메인 대화가 사용자 승인을 받은 뒤 MCP 도구로 합니다. 이 스킬의 산출물은 초안 파일까지이고, documenter에게는 wiki·Notion 쓰기 도구가 없습니다. 초안이 승인을 기다리는 중이라는 사실을 보고서의 「만든 초안 (kb)」에 적어 메인 대화가 이어받게 합니다.
